fix: jours travaillés non colorés au calendrier + badge de version fantôme (v2.1.2)

- Correctif : dans renderCal(), la classe CSS 'work' (jour travaillé) était
  rattachée au mauvais bloc if/else if à cause d'un enchaînement de
  conditions mal branché avec la détection des congés personnalisés. Un jour
  travaillé sans congé n'était donc jamais mis en évidence visuellement dans
  le calendrier des congés. Condition réécrite pour s'appliquer correctement
  dès qu'un jour sans congé a une session enregistrée.

- Correctif : le badge de version en haut de l'écran principal n'existait
  pas dans le HTML alors que le code (openAboutSettings) essayait déjà de le
  mettre à jour via document.getElementById('versionBadgeTop'). Ajout de
  l'élément #versionBadgeTop dans le header (utilisant le style CSS
  .version-badge-topright déjà présent mais orphelin), initialisé au
  chargement de l'app et cliquable vers la page "À propos".

- Bump version : 2.1.1 → 2.1.2 (APP_VERSION + CACHE_VERSION synchronisés).
- Entrée changelog v2.1.2 ajoutée.
